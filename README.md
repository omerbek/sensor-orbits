# Sensor Orbits / Yörünge koreografisi

## Türkçe

[Canlı aracı aç](https://omerbek.github.io/sensor-orbits/).

Üç ölçüm işareti farklı gecikmelerle ortak bir yörünge izler.

## Çalıştırma

`index.html` dosyasını bir tarayıcıda aç. Oynat düğmesini ve zaman çizelgesini kullanarak sekiz saniyelik sahneyi incele. HTML ve Canvas 2D ile çevrimdışı çalışır.


## Sahne ayarları

- Sensör sayısı
- Yatay yarıçap
- Sensör gecikmesi (s)

Sekiz saniyelik zaman çizelgesinden bir kare seçip **PNG indir** ile 720 × 405 piksel dışa aktarabilirsin.

## English

Adjust the count, spacing and paths of orbiting sensor markers.

Open [the live tool](https://omerbek.github.io/sensor-orbits/) or open `index.html` in a browser. Switch between Turkish and English in the page header. Use the timeline to select a frame and **Download PNG** to save it at 720 × 405 pixels.
